## ✨ Recursos

- **3 níveis de dificuldade** — fácil, médio e difícil
- **Quantidade de bombas personalizada** — escolha quantas minas quiser
- **Primeiro clique sempre seguro**
- **Abertura automática** das casas vazias ao redor
- **Cronômetro** e contador de bombas restantes
- **Melhor tempo salvo** no navegador, por nível e por quantidade de bombas
- **Tema claro e escuro** automático, conforme o seu aparelho
- **Funciona no celular** — segure o dedo na casa para colocar a bandeira

## 🎚️ Níveis

| Nível   | Tabuleiro | Bombas |
| ------- | :-------: | :----: |
| Fácil   |   9 × 9   |   10   |
| Médio   |  16 × 16  |   40   |
| Difícil |  16 × 30  |   99   |

Em qualquer nível é possível mudar a quantidade de bombas pelo campo **Bombas**, de 1 até o total de casas menos 9.

## 🎮 Como jogar

| Ação                        | Computador                  | Celular                 |
| --------------------------- | --------------------------- | ----------------------- |
| Revelar uma casa            | Clique esquerdo             | Toque                   |
| Colocar ou tirar a bandeira | Clique direito              | Segurar o dedo na casa  |
| Abrir as casas ao redor     | Clique num número já aberto | Toque num número aberto |
| Reiniciar                   | Clique no rostinho          | Toque no rostinho       |

Cada número mostra quantas bombas existem nas 8 casas vizinhas. Use essa pista para descobrir onde estão as minas e revele todas as outras casas para vencer.

## ▶️ Como rodar

Baixe o projeto e abra o arquivo `index.html` no navegador. É só isso.

```
git clone https://github.com/SEU_USUARIO/campo-minado.git
cd campo-minado
```

Depois dê duplo clique no `index.html`.
