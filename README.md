# Campo Minado

Jogo de Campo Minado em HTML/CSS/JS puro, com três níveis (fácil, médio e difícil).

## Rodar local
Abra o `index.html` no navegador (não precisa de servidor nem de instalação).

## Docker
```
docker build -t campo-minado .
docker run -p 8080:80 campo-minado
```
Acesse http://localhost:8080.
